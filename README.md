# شغف الطاقة — المنصة (نسخة 2)

موقع ثابت بدون بناء (HTML/CSS/JS). عربي (RTL) وإنجليزي (LTR). مساحتان: عميل ومهندس/شركة.

## الملفات
- `calc.js` الحسابات: السطح والتظليل، السلاسل، الكابلات والقواطع، BESS، المالية. كل الافتراضات في `DEFAULTS`.
- `store.js` تخزين محلي (localStorage). استبدل `load/persist` بنداءات API عند وجود خادم.
- `i18n.js` النصوص العربية والإنجليزية.
- `app.js` الهيكل والتنقل والمكونات المشتركة. `customer.js` و`engineer.js` الصفحات.
- `viewer3d.js` العرض الثلاثي الأبعاد (Three.js من CDN).

## النشر
ارفع المجلد كما هو على ريبو GitHub ثم Vercel (Framework Preset: Other). لا تنشره فوق الموقع الحالي قبل المراجعة.

## ما هو تجريبي
- المساحتان تتشاركان نفس البيانات المحلية. الفصل الحقيقي يحتاج تسجيل دخول وصلاحيات وقاعدة بيانات.
- الطلبات تتحفظ على الجهاز ولا تُرسل لأي جهة.
- المعدات قيم نموذجية عامة غير موثقة حتى يُسجَّل لها مصدر في مكتبة المعدات.
- الحسابات الكهربائية وBESS أولية وليست تصميماً معتمداً.
